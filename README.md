# Lineth Garach | Performing Arts Portfolio

## About the Portfolio

A personal performing arts portfolio for Lineth Garach, showcasing her background and experience as a performer, actor, dancer, and developing director. The website highlights performance experience, artistic training, current projects, skills, and a demonstration contact form across five pages:

- Home
- About Me
- Projects
- Skills
- Contact

## Live Website

[View Lineth Garach’s Performing Arts Portfolio](https://halfakiwi.github.io/Portfolio/)

## Features

- Five-page responsive portfolio with layouts for phones and laptops
- Semantic HTML5 structure and shared responsive CSS
- Theatrical design using cream, burgundy, gold, and charcoal
- Responsive mobile navigation built with JavaScript
- Client-side Contact form validation built with JavaScript
- Keyboard-accessible navigation and form controls
- Skip-to-main-content link
- Accessible image alt text
- Lighthouse Accessibility score of 100 on all five pages

## Viewing the Website Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The project uses plain HTML, CSS, and JavaScript. No framework, package installation, build process, or development server is required.
